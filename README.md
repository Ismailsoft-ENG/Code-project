# C Programming Practice

A collection of beginner-level C programs I wrote while learning
programming as a Software Engineering student at NSTU. Each program
focuses on one core concept.

## Topics Covered
- Loops (for, while, nested loops)
- Conditions (if-else, switch-case)
- Calculator programs
- Number problems (factorial, palindrome, reverse number, GCD)
- Math functions (floor, log)

## How to Run

Compile and run any program with GCC:

```bash
gcc program-name.c -o program-name
./program-name
```

Replace `program-name` with the name of the file you want to run.
